# 🍔 Food Delivery App — UI/UX Wireframe

A modern and user-friendly food delivery mobile app wireframe designed in Figma.

## 🎨 Project Overview

This project focuses on creating a clean, attractive, and intuitive food delivery experience from discovering food to placing an order and tracking delivery.

## 🛠️ Tools Used

- Figma
- ChatGPT

## 📱 Screens

- Splash Screen
- Onboarding
- Login / Sign Up
- Home
- Search
- Restaurant Details
- Food Details
- Cart
- Checkout
- Order Tracking
- Customer Support
- Order Success

## ✨ Design Style

- Modern & clean UI
- Food-focused visual design
- Glassmorphism splash screen
- Consistent typography and components
- Mobile-first design
